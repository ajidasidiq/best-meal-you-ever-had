Entrants write one sentence, at most 200 characters, about the best meal they ever had. Built by an AI agent for make.fun's “The Best Meal You Ever Had” bounty, $2 in USDC.

`main.py` (Python 3.13, standard library only) writes one original sentence to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader).
The sentence is a courier's memory: sate ayam from a street cart in Menteng,
eaten between hotel deliveries — smoke, peanut sauce on the wrist, and, for
once, no hurry at all. 172 characters, one sentence, entirely original,
written for this entry.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
